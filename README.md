# TEST-git-mac-os

## 趣味コレクション管理（Hobby Collection Tracker）

自分の趣味に関するアイテムを記録するためのシンプルなWebアプリです。
- 現在所有しているものの一覧管理
- これから購入したものについて、購入日・金額・購入場所を記録
- レシート・納品書を撮影/選択するだけで、店名・購入日・金額・品名をAI（Claude API）が自動読み取り
- 漫画の単行本など、同じシリーズの複数巻をまとめて1つのグループとして管理（例: ドラゴンボール 1〜10巻）
- 写真を撮影/ファイルから選択してサムネイル画像を登録
- タグやメモを付けてブログ記事のネタ作りに活用
- JSON / Markdown / CSV でのエクスポート（ブログ執筆やバックアップ用）
- PCとスマホなど複数端末から同じデータを見る・編集する（同一サーバーへアクセスすることで同期）

### セットアップ

データの保存・同期にサーバーを使う構成のため、`index.html` を直接開くのではなく、必ずローカルサーバーを起動して利用します。

```bash
npm install
cp .env.example .env
# .env を開き、ANTHROPIC_API_KEY にご自身のAPIキーを設定してください（レシート読み取り機能を使う場合のみ必須）
# https://console.anthropic.com/ で取得できます

npm start
# ブラウザで http://localhost:3000 を開く
```

ANTHROPIC_API_KEY を設定しない場合でも、アイテムの登録・編集・一覧表示・エクスポートなどは通常通り利用できます（「レシート・納品書を撮影/選択」機能のみエラーになります）。

### PC・スマホ間でのデータ同期

アイテムのデータはサーバー側のファイル（`server/data/items.json`）に保存されるため、**同じサーバーにアクセスすれば** PC・スマホなど複数端末から同じデータを見る・編集することができます。

1. サーバーを起動しているPCの、Wi-Fi上のローカルIPアドレスを確認します（例: macOSなら「システム設定」→「Wi-Fi」→「詳細」で確認できます。`192.168.x.x` のような形式です）。
2. スマホを同じWi-Fiに接続し、ブラウザで `http://<PCのローカルIP>:3000`（例: `http://192.168.1.23:3000`）を開きます。
3. PC・スマホどちらで登録・編集しても、もう一方の画面を再読み込みすれば最新の内容が表示されます。

外出先などPCと別のネットワークからも使いたい場合は、サーバーをクラウド（Render, Fly.ioなど）にデプロイする必要があります。その際はAPIキーの管理や、第三者がアクセスできないようにする認証の追加もあわせて検討してください（現状は認証なしで、同じネットワーク上の誰でも `/api/items` にアクセスできる想定の構成です）。

### レシート読み取りについて

- 撮影・選択した画像はサーバー（`server/index.js`）経由で Claude API に送信され、店名・購入日・合計金額・主な購入品名を抽出してフォームに自動入力します。
- 自動入力後も内容は保存前に確認・修正できます。誤読があれば手動で直してください。
- 画像はAPI呼び出しのためだけに使用され、アプリ側では保存しません。
- APIの利用には Anthropic アカウントの API キーと、呼び出し回数に応じた費用が発生します。

### シリーズ（巻数）管理について

- 品名欄からフォーカスが外れると、「タイトル 11巻」「タイトル(11)」「タイトル vol.11」のような表記を自動認識し、「シリーズ名」「巻数」欄に候補を入力します。認識結果は保存前に自由に修正・削除できます。
- 同じシリーズ名を持つアイテムが2件以上になると、一覧では自動的に1枚のカードにまとめられ、所有している巻の範囲（例: 1〜3, 5巻）が表示されます。カードを開くと各巻の購入日・金額・購入場所を個別に確認できます。
- 自動認識は品名の末尾の数字を手がかりにした簡易的なパターン照合のため、数字を含む別カテゴリの品名（例: 「iPhone 15」）でも候補が入ることがあります。不要な場合はシリーズ名・巻数欄を空にしてください。

### サムネイル写真について

- フォームの「📷 写真を撮影/選択」からアップロードした写真は、ブラウザ側で自動的に小さいサイズ（長辺480px程度のJPEG）に変換してからサーバーに送信します。フル解像度の写真は保存されません。
- 保存された写真は一覧のアイテムカード（シリーズにまとめた場合は各巻のカード）にサムネイルとして表示されます。
- アイテムを削除すると、対応する写真ファイルもサーバーから削除されます。
- 既存の写真を新しい写真に差し替えて保存すると、差し替え前の写真ファイルもサーバーから自動的に削除されます。編集中に写真をアップロードしても保存せずに「キャンセル」した場合は、その未保存の写真だけが削除され、元の写真はそのまま残ります。

### ファイル構成

- `index.html` — ページ本体
- `css/style.css` — スタイル
- `js/app.js` — アプリのロジック（サーバーとのデータ同期・一覧表示・エクスポート・レシート読み取り・写真アップロード連携など）
- `server/index.js` — 静的ファイル配信 + アイテムデータAPI + 写真アップロードAPI + レシート画像解析API（Claude Vision）を提供するローカルサーバー
- `server/data/items.json` — アイテムデータの保存先（サーバー初回起動時に自動作成。個人データのためGit管理対象外）
- `server/data/images/` — アップロードされたサムネイル写真の保存先（Git管理対象外）
- `.env.example` — サーバー用環境変数のサンプル（`ANTHROPIC_API_KEY` など）

### バックアップ

`server/data/items.json` はGit管理対象外（`.gitignore`）のため、サーバーを新しい環境に移す際は手動でコピーするか、アプリ内の「データの管理」セクションからJSONエクスポート／インポートをご利用ください。
