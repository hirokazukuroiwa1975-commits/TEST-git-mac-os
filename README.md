# TEST-git-mac-os

## 趣味コレクション管理（Hobby Collection Tracker）

自分の趣味に関するアイテムを記録するためのシンプルなWebアプリです。
- 現在所有しているものの一覧管理
- これから購入したものについて、購入日・金額・購入場所を記録
- タグやメモを付けてブログ記事のネタ作りに活用
- JSON / Markdown / CSV でのエクスポート（ブログ執筆やバックアップ用）

### 使い方

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで使えます。

```bash
# 例: ローカルサーバーを立てて開く場合
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

データはブラウザの localStorage に保存されます。他の端末やブラウザに移す場合は
「データの管理」セクションのJSONエクスポート／インポートをご利用ください。

### ファイル構成

- `index.html` — ページ本体
- `css/style.css` — スタイル
- `js/app.js` — アプリのロジック（データ保存・一覧表示・エクスポートなど）
