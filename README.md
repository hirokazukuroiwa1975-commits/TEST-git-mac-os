# TEST-git-mac-os

## 趣味コレクション管理（Hobby Collection Tracker）

自分の趣味に関するアイテムを記録するためのシンプルなWebアプリです。
- 現在所有しているものの一覧管理
- これから購入したものについて、購入日・金額・購入場所を記録
- レシート・納品書を撮影/選択するだけで、店名・購入日・金額・品名をAI（Claude API）が自動読み取り
- 漫画の単行本など、同じシリーズの複数巻をまとめて1つのグループとして管理（例: ドラゴンボール 1〜10巻）
- タグやメモを付けてブログ記事のネタ作りに活用
- JSON / Markdown / CSV でのエクスポート（ブログ執筆やバックアップ用）

### セットアップ

レシート自動読み取り機能を使うには、Anthropic の API キーを使ってローカルサーバーを起動する必要があります。

```bash
npm install
cp .env.example .env
# .env を開き、ANTHROPIC_API_KEY にご自身のAPIキーを設定してください
# https://console.anthropic.com/ で取得できます

npm start
# ブラウザで http://localhost:3000 を開く
```

レシート読み取りを使わない場合は、これまで通り `index.html` を直接ブラウザで開く（または任意の静的サーバーで配信する）だけでも利用できます。ただし「レシート・納品書を撮影/選択」ボタンはサーバー起動時のみ動作します。

```bash
# レシート読み取り機能なしで使う場合の例
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

データはブラウザの localStorage に保存されます。他の端末やブラウザに移す場合は
「データの管理」セクションのJSONエクスポート／インポートをご利用ください。

### レシート読み取りについて

- 撮影・選択した画像はサーバー（`server/index.js`）経由で Claude API に送信され、店名・購入日・合計金額・主な購入品名を抽出してフォームに自動入力します。
- 自動入力後も内容は保存前に確認・修正できます。誤読があれば手動で直してください。
- 画像はAPI呼び出しのためだけに使用され、アプリ側では保存しません。
- APIの利用には Anthropic アカウントの API キーと、呼び出し回数に応じた費用が発生します。

### シリーズ（巻数）管理について

- 品名欄からフォーカスが外れると、「タイトル 11巻」「タイトル(11)」「タイトル vol.11」のような表記を自動認識し、「シリーズ名」「巻数」欄に候補を入力します。認識結果は保存前に自由に修正・削除できます。
- 同じシリーズ名を持つアイテムが2件以上になると、一覧では自動的に1枚のカードにまとめられ、所有している巻の範囲（例: 1〜3, 5巻）が表示されます。カードを開くと各巻の購入日・金額・購入場所を個別に確認できます。
- 自動認識は品名の末尾の数字を手がかりにした簡易的なパターン照合のため、数字を含む別カテゴリの品名（例: 「iPhone 15」）でも候補が入ることがあります。不要な場合はシリーズ名・巻数欄を空にしてください。

### ファイル構成

- `index.html` — ページ本体
- `css/style.css` — スタイル
- `js/app.js` — アプリのロジック（データ保存・一覧表示・エクスポート・レシート読み取り連携など）
- `server/index.js` — 静的ファイル配信 + レシート画像解析API（Claude Vision）を提供するローカルサーバー
- `.env.example` — サーバー用環境変数のサンプル（`ANTHROPIC_API_KEY` など）
