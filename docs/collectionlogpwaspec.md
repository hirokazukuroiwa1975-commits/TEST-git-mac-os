# コレクション台帳 PWA 開発仕様

## 概要
趣味全般(レコード・本・マンガ・ファッション・その他)の所有アイテムと購入履歴を記録するPWA。
ブログ記事のネタ帳としての活用も想定。Claudeアーティファクトで作った試作(単一HTMLファイル)を土台に、
本格的なPWAとして作り直す。

## 必須要件
- 単体で動作するPWA(manifest.json + service worker)
  - ホーム画面に追加可能、standalone表示、オフライン閲覧対応
  - アイコン(192x192 / 512x512)を用意
- データはSQLiteまたは同等のローカルDBで永続化(ブラウザのlocalStorage/IndexedDBの制約に注意)
- スマホでの利用がメイン

## データモデル(アイテム)
- id
- category(レコード / 本・マンガ / ファッション / その他 / カスタム追加可)
- name(タイトル・品名)
- brand(アーティスト・ブランドなど、任意)
- status(既存所有 / 新規購入)
- date(購入日、新規購入時のみ)
- price(価格・円、新規購入時のみ)
- place(購入場所、新規購入時のみ)
- notes(メモ、ブログネタ用)
- photo(写真、任意。アップロード前にクライアント側でリサイズ・圧縮する)
- createdAt

## 画面・機能(試作からの引き継ぎ)
- カテゴリ別タブでの絞り込み(すべて/レコード/本・マンガ/ファッション/その他+カスタム)
- 上部サマリー:総アイテム数、当年の購入額、記録済み購入総額
- アイテム追加フォーム:カテゴリ選択(新規カテゴリ入力可)、既存所有/新規購入の切り替えで購入情報欄の表示切替
- 写真撮影・選択(カメラ起動 or ギャラリー選択)、自動リサイズ(長辺640px目安)してから保存
- 一覧表示:カテゴリ色分けバー、サムネイル、価格、購入日・購入場所、メモ、削除ボタン

## 拡張候補(フェーズ2以降)
- ブログ記事用にアイテム単位でMarkdown/テキストをエクスポートする機能
- 検索・並び替え(価格順、購入日順など)
- レコード用途では将来的に[[record-library-app]](写真からのアーティスト・タイトル自動認識)との連携も検討
